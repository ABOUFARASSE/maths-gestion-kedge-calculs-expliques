# Mathématiques et décisions de gestion — version expliquée

Cette version pédagogique conserve les sept laboratoires de gestion et ajoute, pour chaque simulation, une section **Calculs expliqués**.

Chaque étape présente :

- la formule mobilisée ;
- le remplacement par les valeurs du scénario ;
- le calcul numérique ;
- une interprétation simple en gestion.

Les valeurs par défaut ont été choisies afin que les étudiants puissent refaire la plupart des calculs à la main.

## Laboratoires

1. Arbitrer un budget
2. Prévoir une croissance
3. Choisir un fournisseur
4. Tester la rentabilité
5. Décider à la marge
6. Rechercher un optimum
7. Piloter un lancement de produit

L'application est statique. Python s'exécute dans le navigateur grâce à Pyodide et les graphiques utilisent Plotly.
